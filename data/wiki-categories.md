# Wiki Categories

Canonical subdirectories for notes in `wiki/`. Claude reads this before filing any new note.

| Category | Scope |
|----------|-------|
| `technology/` | AI, software, tools, tech industry |
| `learning/` | Education, cognition, skill development |
| `finance/` | Markets, investing, economics |
| `productivity/` | Workflows, management, personal effectiveness |
| `others/` | Staging area for uncategorized notes — revisit with /kb-reorg |
