## Summary

Ben Thompson argues that AI agents are replacing pre-built app UI the way messaging once became mobile's "killer app," using Meta's Muse and Microsoft's new Copilot "super app" as evidence. He contends the internet's old scarcity — discovery — is being replaced by a new one, human "volition," with agents becoming the gatekeepers between users and every underlying service. Thompson concludes Meta and Microsoft hold early advantage in this race because of their existing massive consumer and enterprise distribution.

## Core Concepts

- **[[Aggregation Theory]]**: Thompson's framework applied to agents — value shifts to whichever layer sits closest to the user and controls access to underlying apps and services.
- **Jobs to Be Done**: Thompson's 2013 rebuttal of Zuckerberg's "Facebook Home," arguing phones succeed by serving many discrete needs, not one dominant social interface.
- **[[Muse]]**: Meta's AI agent, demonstrated building a custom recipe app from saved Instagram content; each user reportedly gets a real virtual machine, pairing AI with a deterministic computer.
- **The Infinite App**: UI generated on demand for a single user's need, made viable because generation is now disposable and cheap — Thompson's term for agent-built, single-purpose interfaces.
- **[[Volition]]**: The new scarcity Thompson identifies — as discovery becomes trivial via agents, human inspiration/motivation to act becomes the bottleneck, and agents become gatekeepers to every app.
- **[[Microsoft Copilot]] "super app"**: Bundles chat, coding, and the persistent enterprise agent **[[Autopilot]]**; [[Satya Nadella]] frames it as a "new OS for work," echoing Thompson's 2020 "OS for SaaS" argument about Teams.
- **Distribution advantage**: Thompson's closing argument — Meta (consumer) and Microsoft (enterprise) start the agent race ahead because they already own the primary distribution surface for their respective audiences.

## Key Takeaways

- **Messaging thesis revisited**: Thompson's 2014 "messaging as killer app" thesis predates WhatsApp's acquisition by Facebook.
- **151 → 689 apps**: Thompson's home screen app count grew this much, but core categories stayed stable.
- **Muse's VM**: Each Muse user gets a real virtual machine — deterministic computing paired with AI is what makes agents usable.
- **Discovery is solved, volition is scarce**: Agents remove app-discovery friction; human motivation to act becomes the new bottleneck.
- **Salesforce's Dreamforce bet**: Charging extra to integrate with agents like [[Claude]] looks risky given the trajectory toward computer-using AI.
- **Agent lock-in**: Whoever becomes a user's primary agent gains value through accumulated context and access — a compounding moat.

## 🧠 First Principles & Mental Models

- **[[Platform Lock-In]]**: Agents gain durable value through accumulated context and access, meaning switching agents later means losing that history — the same lock-in logic as data moats, applied to a conversational interface instead of stored documents.
- **[[Comparative Advantage]] of Distribution**: Thompson's bet on Meta and Microsoft rests on their pre-existing reach (consumer devices, enterprise seats) rather than model quality — distribution, not capability, is the scarce resource that decides the early agent race.

## 🃏 Review Questions

**Q1**: What is Thompson's central argument about the shift from apps to agents?
**A**: AI agents and natural-language interfaces are replacing pre-built, write-once UI, mirroring how messaging became mobile's killer function — and the company that becomes a user's primary agent will control access to every underlying app or service.

**Q2**: How does Meta's Muse technically enable "the infinite app," and why does that matter?
**A**: Muse pairs AI with a real virtual machine for each user, giving agents actual deterministic computing rather than just conversation — this is what lets Muse generate disposable, single-purpose UI (like a custom recipe app) cheaply on demand.

**Q3**: What new scarcity does Thompson say replaces the internet's old discovery problem, and what does that imply for competitive strategy?
**A**: Human "volition" — the motivation to act — becomes scarce once agents solve discovery; this implies the winning companies will be those with the distribution to become users' default agent, since agents accumulate context and lock-in over time (Thompson names Meta and Microsoft as early favorites).
