## Summary
Proprietary data advantages and network effects are economically different sources of defensibility, and conflating them leads founders to overestimate their moat and investors to double-count it. A network effect arises when participants make the product more valuable to each other, while a data advantage arises when the company learns from usage. The strongest AI companies run both engines, and four diligence questions help separate them.

## Core Concepts
- [[Network Effects]]: additional participants increase product value to other participants, as in Uber's rider-driver "liquidity network effect."
- [[Data Moat]]: learning from customer interactions improves the product, even if customers never interact with each other.
- [[Flywheel Effect]]: the more users, more data, better model loop that investors often over-credit.
- [[Economic Moat]]: durability differs; network effects harden with scale while data advantages tend to erode.
- [[Uber]]: example of both mechanisms, a marketplace network plus data-driven matching, pricing and forecasting.
- [[Palantir]]: isolated customer data and governance give a data and trust strategy, not automatically a network effect.
- [[Gaurav Tewari]]: investor who tests the two advantages separately in AI underwriting.
- [[Synthetic Data]]: one way a competitor can replicate a supposed data moat.

## Key Takeaways
- **Two Engines**: Network effects come from participation; data advantages come from learning.
- **Core Test**: Does a participant add value for users, or only information for the company?
- **Different Durability**: Network effects harden with scale; data advantages are often transient.
- **Volume Is Not the Moat**: The learning curve matters, not the number of observations.
- **Replication Risk**: Competitors can license, synthesize, or engineer around comparable data.
- **Strongest Case**: Platforms where participants and the resulting data feed each other.
- **Four Questions**: Contribution, beneficiary, proprietary status, and marginal impact of incremental data.

## 🧠 Core Principles

**T1. Value from participation differs from value from learning** — A network effect raises value for existing users because others are present; a data advantage raises value because the company learns. Counting one as the other double-counts the moat. · *model:* [[Network Effects]]

## 🃏 Review Questions

**Q1**: Why should investors not treat a data advantage and a network effect as the same moat?
**A**: They are economically different: a network effect depends on other participants being present, while a data advantage comes from what the company learns. Conflating them overstates the moat and double-counts the same advantage.

**Q2**: Why can a company with billions of observations still lack a data moat?
**A**: If a competitor can obtain comparable data, license it, generate synthetic examples, or catch up through engineering, volume alone gives no edge. The learning curve, not volume, is the moat.

**Q3**: What four questions should investors ask when underwriting an AI moat?
**A**: What does a new participant contribute, who benefits from it, is the data genuinely proprietary, and does incremental data still measurably improve outcomes? If the honest answer is only "more customers give us more data," it is not a network effect.
