## Summary

Anthropic has unified its previously separate Claude Chat and Cowork interfaces into a single window, also folding in Artifacts and Claude Design. The consolidation removes the cognitive overhead of choosing the right tab, with Claude now automatically routing requests. New features — Presentations, Docs, and cross-device continuity — are rolling out first to Pro and Max subscribers.

## Core Concepts

- **[[Anthropic]]** merged the distinct [[Claude Chat]] and [[Claude Co-work]] tabs into one unified interface, eliminating tab-switching for users.
- **Automatic routing**: [[Claude]] now determines which underlying capability best fits each request, replacing manual mode selection.
- **Presentations**: Users can create, edit, present, and export slides as PDF or PowerPoint directly inside the interface.
- **Docs**: Collaborative document creation with [[Claude]], shareable via link and editable on mobile.
- **Cross-device continuity**: Work started on desktop can be monitored and continued on mobile within the same session.
- **Availability**: Initially limited to Pro and Max plan subscribers on web, desktop, and mobile; free and team tiers to follow.
- **Memory layer context**: Builds on Cowork's earlier memory upgrade that lets Claude retain user context across separate chat sessions.

## Key Takeaways

- **Unified window**: Chat, Cowork, Artifacts, and Claude Design now share one interface.
- **Auto-routing removes friction**: Claude selects the right capability without user input.
- **Presentations added**: Slide creation and export (PDF/PowerPoint) is now native.
- **Docs are collaborative and shareable**: Links enable external editing on mobile.
- **Cross-device continuity**: Seamless handoff between desktop and mobile.
- **Staged rollout**: Pro/Max first; free and team tiers later.

## 🧠 First Principles & Mental Models

- **[[Cognitive Load Reduction]]**: Merging tabs into one window directly reduces the decision overhead users faced when choosing between Chat and Cowork — fewer modes to reason about means faster task initiation.
- **[[Progressive Disclosure]]**: Surfacing a single unified interface while keeping the underlying capabilities intact is a classic progressive disclosure pattern — complexity is hidden until the user needs it, lowering the barrier to entry.
