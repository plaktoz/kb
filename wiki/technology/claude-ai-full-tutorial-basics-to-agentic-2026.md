## Summary

This tutorial provides a structured three-tier overview of Claude AI's full feature set in 2026, progressing from free beginner features through power-user capabilities to advanced agentic tools. The presenter, Kian, covers how Claude differs from competitors through its safety-focused design and honest uncertainty acknowledgment. The guide aims to help users understand where they are in the Claude ecosystem and what capabilities exist beyond the basic chat interface.

## Core Concepts

- **[[Claude AI]]** — [[Anthropic]]'s AI assistant, positioned as safety-focused and less prone to confident wrong answers than competitors
- **[[Claude Model Tiers]]** — Three models: [[Haiku]] (fast/lightweight), [[Sonnet]] (everyday workhorse), [[Opus]] (deep reasoning for hard problems)
- **Level 1 - Beginner Features**: Chat interface, [[Web Search]] toggle, [[Artifacts]] (interactive visual outputs), [[Memory]] (global cross-conversation context), [[Claude Projects]] (workspace isolation), [[Custom Style]] (writing voice control)
- **Level 2 - Extended Capabilities**: [[Claude Connectors]] (live integrations with Gmail, Drive, Slack, Notion), [[Claude Skills]] (reusable capability modules), [[Extended Thinking]] (step-by-step reasoning mode), [[Research Mode]] (autonomous multi-source research taking 5–45 minutes)
- **Level 3 - Agentic Tools**: [[Claude Co-Work]] (file system access via desktop app), [[Claude Code]] (terminal/editor-based software engineering agent), [[Computer Use]] (screen control and UI automation)
- **[[Claude Pricing]]** — Free (Level 1 with limits), Pro at $20/month (all levels), Max at $100–$200/month (heavy/all-day agentic use)

## Key Takeaways

- **Model Selection**: Haiku = speed, Sonnet = 80% of use cases, Opus = complex reasoning tasks.
- **Memory Import**: Claude lets you migrate context from other AI tools (e.g., ChatGPT) into its memory system.
- **Skills vs. Prompts**: Skills save reusable instruction sets, eliminating repetitive prompting for recurring workflows.
- **Extended Thinking**: Enables step-by-step reasoning for strategic, financial, or multi-step problems.
- **Research Mode**: Autonomous deep research (5–45 min) vs. web search (single-answer lookup).
- **Co-Work**: Desktop app feature — Claude reads a folder and works through files autonomously.
- **Claude Code**: Lives in terminal/editor; reads entire codebase before making changes; catches and retries errors.
- **Computer Use**: Screen-level automation for structured, repetitive tasks; still maturing.
- **Pricing Rule of Thumb**: Start free → upgrade to Pro ($20) when hitting limits → Max ($100+) only for all-day agentic workloads.

## 🧠 First Principles & Mental Models

- **[[Progressive Disclosure]]**: The three-tier structure mirrors how good tools surface complexity gradually — beginners get immediate value without being overwhelmed, while power users can unlock deeper capability when ready. This is why most users never discover agentic features: the interface doesn't force the learning curve.
- **[[Composability]]**: Skills, connectors, and agentic tools are designed as modular building blocks rather than monolithic features — each layer can be combined with others, letting users assemble custom workflows without needing to re-engineer from scratch each time.
