## Summary

Dan Martell walks through 16 Claude features that most users overlook, progressing from basics (memory import, model selection, connectors) through interactive outputs (artifacts, visuals, projects, voice) to advanced agentic tools (Cowork, scheduled tasks, Dispatch, Claude Code, Channels, Skills, Design). The framing: most users treat Claude like a search engine, missing 90% of its leverage.

## Core Concepts

- **[[Claude AI]]**: Anthropic's AI assistant with three model tiers and an expanding surface area from chat to full computer-use agentic workflows.
- **[[Claude Model Tiers]]**: Haiku (fastest, cheapest — bulk data tasks), Sonnet (everyday default), Opus (deep pattern analysis and complex reasoning). Adaptive mode auto-selects.
- **[[Claude Connectors]]**: Native integrations for Gmail, Google Calendar, Slack, Notion, GitHub, Google Drive — enabling Claude to read, search, and act inside live data sources.
- **[[Artifacts]]**: Interactive mini-apps built inside chat — editable spreadsheets, forms, dashboards — removing the need to switch tools for simple interactive output.
- **[[Claude Co-Work]]**: Desktop app giving Claude access to the local file system and computer control ("Claude's hands doing the work"), enabling autonomous multi-step task execution.
- **[[Claude Scheduled Tasks]]**: Co-Work's `/schedule` command for recurring automated jobs (e.g., daily inbox summary) — replaces manual chief-of-staff tasks.
- **[[Claude Dispatch]]**: Mobile app paired with Co-Work via QR code, enabling remote triggering of Co-Work automations from a phone.
- **[[Claude Code]]**: Terminal-based AI software engineer that reads an entire codebase and builds or modifies software in plain English.
- **[[Claude Channels]]**: iMessage, Telegram, or Discord bots paired with Claude Code in the terminal — enabling remote coding from mobile as long as the desktop is running.
- **[[Claude Skills]]**: Reusable instruction modules for repeatable tasks. Community-built skills available on GitHub; popular example: "Humanizer" skill that rewrites AI-sounding text into natural prose.
- **[[Claude Design]]**: Newest Anthropic release (at time of filming) at `claude.ai/design` — generates pitch decks, one-pagers, landing page mock-ups, and motion graphics with brand-guide matching. Anthropic has partnered with Adobe.

## Key Takeaways

- **Gmail power move**: Share a Claude account with an assistant connected to your inbox — assistant can self-serve information retrieval without asking you.
- **Calendar as business coach**: Give Claude quarterly goals, then ask it to analyze calendar + email alignment — surfaces whether time allocation matches stated priorities.
- **Project transcripts**: Load all coaching-call transcripts into a Project linked to Google Drive; query for stories or examples by topic for content creation.
- **Voice mode utility**: Talk 3x faster than typing; useful while mobile; full transcript available for reuse.
- **Chrome extension scope**: Takes page snapshots, scrapes data, clicks buttons, runs analysis autonomously inside the browser.
- **Cowork example workflow**: "Pull last month's HubSpot sales numbers → Google Sheet → summary chart → post to Slack before Monday 9am" — fully automated.
- **Claude Code adoption pattern**: Martell shut down his company for 2 days to train all staff; non-technical CEO built a full dashboard app after 3 days with zero coding background.
- **Channels setup**: Create bot (Telegram/iMessage/Discord) → pair with Claude Code terminal → configure API keys → code from anywhere.
- **Claude Design trajectory**: Anthropic-Adobe partnership signals major disruption of the design workflow. "This is the worst it's ever going to be."

## 🧠 First Principles & Mental Models

- **[[Leverage Stacking]]**: Each feature layer (connectors → artifacts → Cowork → Code) multiplies the previous one — a calendar connector alone saves minutes; combined with scheduled tasks and Dispatch, it removes entire categories of recurring human work.
- **[[Skill vs. Knowledge Bottleneck]]**: The non-technical CEO who built a dashboard illustrates that the bottleneck is no longer coding ability but the capacity to describe what you want clearly. Claude Code shifts the scarce resource from syntax knowledge to requirement articulation.
- **[[Progressive Tool Adoption]]**: Martell's closing advice — "you don't need to do them all, you just need to know they exist" — reflects a discovery-first adoption model: knowing a tool exists reduces activation energy when the right use case appears.
