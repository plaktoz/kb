## Summary

TigerGraph is a graph database platform that helps organizations connect, analyze, and learn from complex data relationships in real time. Its solutions span revenue growth, risk management, and operational efficiency use cases across industries such as financial services, healthcare, and advertising. The platform's foundational capabilities include AI/ML integration, time series analysis, and geospatial analysis.

## Core Concepts

- **[[Graph Database]]**: TigerGraph's core technology for modeling and querying highly connected data at scale.
- **[[Customer 360]]**: A unified, real-time customer profile built by linking data across touchpoints using graph traversal.
- **[[Entity Resolution]]**: Resolving data ambiguity by identifying and merging records that refer to the same real-world entity.
- **[[Anti-Money Laundering (AML)]]**: Real-time detection of suspicious financial patterns using graph relationships between accounts, transactions, and actors.
- **[[Fraud Detection]]**: Identifying fraudulent behavior by analyzing network connections rather than individual data points in isolation.
- **[[Supply Chain Analysis]]**: Real-time event analysis across interconnected supply chain nodes using graph topology.
- **[[Recommendation Engine]]**: Personalized product or content recommendations derived from graph-based similarity and relationship traversal.
- **[[Cybersecurity Threat Detection]]**: Proactive threat deflection by mapping relationships between network assets, users, and attack vectors.

## Key Takeaways

- **Revenue growth**: Graph enables Customer 360, entity resolution, and real-time recommendations.
- **Risk reduction**: AML, fraud detection, and cybersecurity benefit from relationship-aware analysis.
- **Operational efficiency**: Energy, network, and supply chain management all use real-time graph analytics.
- **AI/ML integration**: Foundational layer supports machine learning on top of graph-structured data.
- **Geospatial + time series**: Natively handles location-based and temporal data patterns.
- **Industry verticals**: Financial services, healthcare/life sciences, advertising, media, and entertainment.
