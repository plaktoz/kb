## Summary

Every.to rewrote its ChatGPT and OpenClaw workflow guides — not because models changed, but because the surrounding infrastructure did. The updates reflect how apps, interfaces, credentials, and maintenance overhead now shape AI outcomes as much as model capability itself.

## Core Concepts

- [[ChatGPT]] interface split into three distinct modes: **Chat** (quick questions), **Work** (longer assignments), and **Codex** (software tasks) — each demanding different usage patterns.
- [[OpenClaw]] — a personal AI agent setup that requires ongoing maintenance; expired credentials and broken integrations can render a stronger model completely ineffective.
- [[AI Infrastructure]] — the layer of apps, permissions, tools, and maintenance routines wrapped around a model; increasingly the limiting factor in real-world AI performance.
- [[Shared Company Agent]] — Every.to is experimenting with a single agent living in [[Slack]] rather than individual personal Claws, trading personalization for reduced maintenance burden.

## Key Takeaways

- **Model version is one variable**: apps, tools, permissions, and maintenance shape outcomes equally.
- **ChatGPT now has three interfaces**: Chat, Work, and Codex — each suited to different task types.
- **New ChatGPT features**: `/goal` command for persistent objectives, cloud vs. local project types, scheduled tasks, thread automations, and browser access with signed-in profiles.
- **OpenClaw maintenance reality**: expired credentials and broken integrations routinely break personal agents regardless of model quality.
- **"A stronger model still can't log in when a credential expires"** — the guide surfaces the human overhead of personal agent upkeep.
- **Shared agent tradeoff**: a company-wide Slack agent reduces per-person maintenance at the cost of personalization.

## 🧠 First Principles & Mental Models

- **[[Layers of Abstraction]]**: AI capability is realized through stacked layers — model, harness, credentials, integrations — and any layer can be the bottleneck. Focusing only on the model layer produces the illusion of control while the infrastructure layer silently degrades.
- **[[Maintenance Debt]]**: personal agents accumulate upkeep obligations over time (expired credentials, stale memory, broken integrations) analogous to technical debt — visible only when something breaks, but accruing continuously.
