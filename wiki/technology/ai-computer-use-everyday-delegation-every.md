## Summary

Every staffers share how [[Computer Use]] capabilities in AI models like [[Astra]] and [[Codex]] have unlocked a new class of task delegation: not complex reasoning, but the annoying, deferred work humans perpetually avoid. Mike Taylor, Every's head of evals, initially dismissed Astra until its computer use features made it his daily driver, handling everything from school forms to bulk hyperlink verification across a book manuscript.

## Core Concepts

- **[[Computer Use]]** — AI model capability to click, type, and scroll through apps autonomously on behalf of the user
- **[[Astra]]** — [[OpenAI]]'s model that Every staffers found compelling specifically for its computer use features
- **[[Codex]]** — [[OpenAI]]'s coding-focused model used for slide deck copy drafting and template-based Google Slides automation
- **[[Task Delegation]]** — shifting deferred or annoying tasks to an AI agent rather than to a human assistant
- **[[Slide Deck Workflow]]** — a repeatable pattern: design reference slides → draft copy with Codex → Codex builds full deck → feed corrections back as rules

## Key Takeaways

- **Low-complexity tasks are the sweet spot**: Computer use excels at annoying but not hard work.
- **Bulk verification unlocked**: Astra checked every hyperlink in a book manuscript and compiled a problem spreadsheet.
- **Everyday delegations**: calendar entry, marketplace selling, phone plan negotiation, IT troubleshooting, ISP transfers.
- **Slide deck pattern**: Codex builds from reference slides + copy, then learns corrections as saved rules.
- **Procrastination → delegation**: Computer use converts deferred items into assignable ones.
- **Requires escalation mindset**: Start small (forms), then expand (video editing, spreadsheet automation).

## 🧠 First Principles & Mental Models

- **[[Activation Energy]]**: The barrier to starting an annoying task is often higher than the task itself — computer use lowers activation energy to near zero by removing the need for human initiation, which is why it converts chronic procrastination items into delegated tasks.

## 🃏 Review Questions

**Q1**: What is the central argument of the article about AI computer use?
**A**: Computer use does not shine on complex tasks but on the annoying, deferred ones humans avoid — it converts procrastination items into delegatable work.

**Q2**: How did Mike Taylor use Astra's computer use to verify hyperlinks in a book manuscript?
**A**: Astra opened each URL, verified it loaded correctly, and autonomously compiled a spreadsheet of problem links — a tedious bulk task that would otherwise require manual clicking through every reference.

**Q3**: How can practitioners replicate the slide deck workflow described by Douglas Brundage?
**A**: Design a few reference slides manually, draft copy with Codex, have Codex build the full deck from your templates in Google Slides, then review and feed corrections back so Codex saves them as reusable rules.
