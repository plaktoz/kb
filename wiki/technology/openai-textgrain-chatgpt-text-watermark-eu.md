## Summary
[[OpenAI]] will add an invisible watermark to text generated by [[ChatGPT]] and [[Codex]] in the European Union, to comply with the transparency rules of the [[EU AI Act]] that took effect on August 2. The method, called [[textGrain]], subtly shapes the model's word choices so a detector holding a secret key can spot the pattern. OpenAI admits the watermark can be weakened by editing and won't make it a global default at launch. That contrasts with [[Anthropic]], which applies its [[Claude]] watermark worldwide.

## Core Concepts
- **[[textGrain]]**: OpenAI's text watermarking method, described in a technical report co-written with researchers from the University of Pennsylvania and Yale. A secret key sorts next-word predictions, and hundreds of these small nudges add up to a pattern the detector can find using only the text and the key.
- **[[EU AI Act]] transparency rules**: Since August 2, AI companies must mark AI-generated content in a way other systems can identify (see [[eu-ai-act-transparency-rules-august-2026]]).
- **Regional scoping**: The watermark rolls out over the coming weeks to eligible ChatGPT and Codex users on all plans, but only in the EU. API developers anywhere can turn it on for select models; it is off by default.
- **Restricted detector access**: At first, only approved researchers and expert organizations can use the detector, because of reliability limitations.
- **Anthropic comparison**: Two months earlier, Anthropic announced it would watermark Claude's text worldwide (see [[how-claudes-text-watermark-works]]). Some Claude users pushed back, arguing they supplied "the instructions, context, decisions" while Claude was just "the tool."
- **[[EU Code of Practice on Transparency of AI-Generated Content]]**: Anthropic, Google, Meta, Microsoft and OpenAI have all committed to following it.

## Key Takeaways
- **Survives copy-paste**: The watermark lives in the word choices, so it travels with the text.
- **Privacy**: The watermark doesn't identify the user.
- **No quality cost**: OpenAI saw no meaningful change in model performance.
- **Edit vulnerability**: Replacing 10% of words with synonyms cut detection from ~92% to 66%.
- **Hard cases**: Short passages, math answers and translated text are harder to detect.
- **Asymmetric evidence**: A missing watermark "does not prove human authorship."
- **Limited signal**: Shows OpenAI involvement, not how much human judgment went in.
- **Prior hesitation**: OpenAI shelved an earlier watermark over fears users would defect (WSJ, 2024).

## 🧠 First Principles & Mental Models

- **[[Collective Action Problem]]**: OpenAI held off on an earlier watermark because users might switch to rivals that didn't watermark. Unilateral action loses users, so it took a binding regulation (the EU AI Act) and a shared industry code to make adoption viable, and only where the rule applies.
- **[[Absence of Evidence Is Not Evidence of Absence]]**: A detected watermark is strong evidence of OpenAI involvement. A missing one tells you little, since the text may be short, edited, translated, or from another AI.

## 🃏 Review Questions

**Q1**: What is OpenAI doing with ChatGPT's text in the EU, and why?
**A**: It is adding an invisible watermark to text generated by ChatGPT and Codex in the EU to comply with the EU AI Act. Those transparency rules took effect August 2 and require AI-generated content to be machine-identifiable.

**Q2**: How does textGrain work, and how robust is it?
**A**: A secret key sorts next-word predictions, and hundreds of these nudges add up to a pattern a detector can find using only the text and the key. Swapping 10% of words for synonyms dropped detection from about 92% to 66%.

**Q3**: How should you interpret a watermark check on a piece of text?
**A**: A detected watermark suggests an OpenAI system generated or processed part of the passage, but not how much human editing or creativity went into it. A missing watermark does not prove a human wrote it.
