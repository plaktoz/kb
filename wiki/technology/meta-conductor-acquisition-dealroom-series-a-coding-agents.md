## Summary
Meta has acquired Conductor, a startup whose platform runs multiple AI coding agents in parallel in isolated workspaces; terms were not disclosed. The deal is expected to support Meta's next generation of AI coding products and reflects a widening race to own developer tools, with OpenAI announcing a similar acquisition the same day.

## Core Concepts
- [[Meta]]: Acquirer of [[Conductor]]; financial terms undisclosed.
- [[Conductor]]: Founded in 2024; CEO [[Charlie Holtz]] and CTO [[Jackson de Campos]]; raised a $22 million Series A from Spark and Matrix in March 2026.
- [[Parallel Coding Agents]]: Engineers run several agents at once in isolated workspaces, then review, open pull requests for, and merge their work.
- [[Claude Code]], [[Codex]], and [[Cursor]]: Supported first-party agents, used with developers' own subscriptions and keys.
- [[OpenAI]]: Said the same day it plans to acquire another developer tools startup.

## Key Takeaways
- **Deal**: Meta acquired Conductor; terms not disclosed.
- **Funding History**: $22 million Series A from Spark and Matrix in March 2026.
- **Product**: Isolated workspaces per agent, with review, pull request, and merge workflow.
- **Bring Your Own Agent**: Works with Claude Code, Codex, and Cursor via developers' own keys.
- **Why Now**: Coding is a key route to wider AI adoption and enterprise spending.
- **Model Testing Ground**: Stronger programming performance can improve underlying models.
- **Race Signal**: Meta and OpenAI both moved to lock up coding products on the same day.
