## Summary

Databricks and Microsoft extended their strategic Azure partnership into the 2030s, with Databricks committing to run its own core operations on Azure Databricks and adopt Microsoft's next-generation Cobalt 200 chips for AI workloads. The deal deepens integration of Databricks' Genie and Unity AI Gateway across Microsoft 365, Teams, Copilot and Power BI, and follows a $188B Databricks funding round plus other Microsoft AI infrastructure deals with AMD and Mistral the same week.

## Core Concepts

- **[[Microsoft]]** — holding; extended its Azure partnership with Databricks into the 2030s
- **[[Databricks]]** — will run its own core operations on Azure Databricks
- **[[Azure Cobalt]]** — Microsoft's Arm-based custom processors, upgrading to Cobalt 200
- **[[Unity AI Gateway]]** — Databricks tool governing models, agents, and costs, integrated into Microsoft products
- **[[Enterprise AI]]** — broader theme of deepening cloud/AI infrastructure alliances

## Key Takeaways

- **Databricks-Microsoft Azure partnership** extended into the 2030s.
- **Databricks will run its own operations** on Azure Databricks.
- **Cobalt 200 chips** promise up to 50% better AI performance.
- **Databricks valued at $188B** in a funding round closing this summer.
- **Part of a broader Microsoft AI push**, alongside new AMD and Mistral deals.
