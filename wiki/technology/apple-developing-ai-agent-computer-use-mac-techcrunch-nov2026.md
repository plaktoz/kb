## Summary
Bloomberg spotted an Apple job listing for a senior engineering manager to build an "AI agent that can use a computer", handling apps, web, commands and coding. At the same time, Apple is making it harder for third-party agents to gain full control of Macs, with macOS 27.3 warnings. The in-house agent is reportedly early-stage, possibly launching as soon as the end of next year.

## Core Concepts
- [[Apple]]: building an in-house [[AI Agents]] capable of computer work under the [[John Ternus]] era.
- [[Computer-Use Agents]]: agents that browse, work across apps, run commands, write and debug code, and call services.
- [[macOS 27.3]]: will warn users against granting full access to third-party agents.
- [[Third-Party Agent Restrictions]]: Apple's October developer notice promised "very explicit user action" for extraordinary access.
- [[Anthropic]], [[OpenAI]] and [[Meta]]: rivals that already launched computer-work agents; Meta has the Muse agent line.
- [[Privacy]]: the listing stresses private operation with Apple polish.

## Key Takeaways
- **Job Listing**: Apple seeks a manager for an agent that "uses a computer".
- **Scope**: Multi-step tasks across apps, browsers, command lines, code and APIs.
- **Dual Strategy**: Building its own agent while restricting third-party agents' full access.
- **Competition**: Anthropic, OpenAI and Meta already offer computer-use agents.
- **Timeline**: Early stage; launch possibly as soon as the end of next year.
