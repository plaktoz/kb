## Summary

Microsoft is freezing new-feature development for Microsoft 365 and Copilot on Windows 10 after version 2608 (rolling out August 2026), while continuing security-only updates through October 2028 — an incentive designed to push the roughly 17–30% of PCs still on Windows 10 toward Windows 11.

## Core Concepts

- **[[Frozen Development State]]**: Office apps on Windows 10 will keep receiving security patches through October 10, 2028, but no new features after version 2608 — effectively capping the platform's software experience.
- **[[Windows 10 Holdout Problem]]**: According to HP and independent IT data, roughly 17–30% of PCs still run Windows 10, and Microsoft has admitted end-of-support messaging is no longer effectively driving Windows 11 upgrades.
- **[[OneDrive Version Gating]]**: OneDrive continues updating on Windows 10 22H2 through October 2028, but stops updating entirely on older Windows 10 versions — a second lever pushing users toward the latest supported configuration.
- **[[Copilot-Driven Feature Gap]]**: Most recent Office feature development has centered on Copilot and AI agents (e.g., Copilot editing in PowerPoint, agent support in Word) — the exact capabilities Windows 10 users will now miss going forward.

## Key Takeaways

- **Microsoft 365 version 2608** (rolling out August 2026) is the last major feature release for Windows 10; devices then get only security updates until October 10, 2028.
- **OneDrive updates continue on Windows 10 22H2** through the same 2028 date, but the desktop app stops updating on older Windows 10 builds entirely.
- **Most recent Office feature work has been Copilot/agent-focused**, meaning the "loss" for Windows 10 users is concentrated in AI capabilities rather than core functionality.
- **Windows 10 holdouts remain stubborn**: Microsoft itself has admitted its own end-of-support push is no longer driving Windows 11 adoption as effectively as before, partly due to rising PC prices.

## 🃏 Review Questions

**Q1**: What is the core claim of this article?
**A**: Microsoft is limiting new Microsoft 365 and OneDrive features on Windows 10 — while still providing security updates through 2028 — as a soft incentive to push remaining users toward Windows 11.

**Q2**: What exactly changes for Windows 10 users once version 2608 ships?
**A**: Office apps stop receiving new features (most recent updates have been Copilot- and agent-focused) but continue getting security updates through October 10, 2028; OneDrive keeps updating only on Windows 10 22H2.

**Q3**: Why might this strategy fail to move many Windows 10 holdouts?
**A**: Most recent Office feature additions have been AI/Copilot capabilities that many users don't rely on, and holdouts are already resistant to upgrading due to hardware costs — meaning the "FOMO" lever may not outweigh the cost and inertia of switching.
