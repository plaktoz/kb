## Summary

Active recall (the retrieval action) and spaced repetition (the review timing) solve different problems and work best combined into a single loop: attempt from memory, check against a source, classify the result as wrong/incomplete/effortful/easy, and use that classification to set the next review interval. Neither method alone is sufficient — recall exposes an "illusion of competence," while spacing exposes short-lived success that fades within days. This complements the algorithmic/scheduling focus of [[science-of-spaced-repetition]] with a practical, subject-by-subject workflow.

## Core Concepts

- [[Active Recall]] — deliberately retrieving an answer, diagram, or explanation from memory before checking it, distinct from passive rereading
- [[Spaced Repetition]] — the timing system that decides when a retrieval attempt should recur, adaptive to performance rather than a fixed calendar
- [[Illusion of Competence]] — the failure mode active recall specifically exposes: material feels familiar even when it can't be produced unaided
- [[Desirable Difficulties]] — Bjork's framework underlying why self-selected, performance-based retrieval intervals outperform a rigid preset schedule
- [[Combined Study Loop]] — a six-step workflow: define target, create matching prompts, attempt before revealing, classify the result, choose next interval, vary retrieval format over time

## Key Takeaways

- **Different failure modes**: active recall catches false familiarity; spacing catches knowledge that fades between sessions
- **Four-way classification** (wrong / incomplete / effortful / easy) should drive scheduling, not a uniform interval chart
- **Prompt format must match the assessment**: flashcards suit compact facts, but solving/interpreting/arguing tasks need problems, diagrams, and scenario prompts instead
- **2023 systematic review** (health professions education) and a **2026 meta-analysis** (medical education) both found positive but heterogeneous effects — evidence supports the methods without a one-size-fits-all formula
- **Common failure**: flipping a card too fast trains recognition, not recall — a genuine attempt requires enough time to actually produce an answer

## 🧠 First Principles & Mental Models

- **[[Metacognition]]**: The article's core distinction — active recall as evidence-generation, spacing as evidence-use — is fundamentally a metacognitive loop: you can't calibrate what you actually know versus think you know without a retrieval attempt that has a clear right/wrong outcome to update on.
