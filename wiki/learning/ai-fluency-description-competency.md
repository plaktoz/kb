# AI Fluency: Description Competency

**Source:** https://www.youtube.com/watch?v=DmgujoZ1mmk (Anthropic / Ringling College / UCC — AI Fluency: Framework & Foundations, Lesson 6)

Description is the communication layer of AI fluency — going far beyond "clever prompts." It covers how to explain tasks, provide context, steer conversations, guide reasoning, and build an environment where both human and AI can do their best work.

## Three Elements of Description

### 1. Product Description — Define What You Want
Clearly specify the desired output so the AI does not have to guess.

Key elements to include:
- **Context**: What is the background for this request?
- **Task**: Exactly what should the AI do?
- **Format**: What shape should the output take?
- **Audience & style**: Who is this for and what tone is appropriate?

> "It's like the difference between asking someone to make dinner versus providing a detailed recipe with ingredients and cooking instructions."

Setting explicit requirements reduces misalignment and iteration cycles.

### 2. Process Description — Guide How AI Works
Sometimes *how* the AI tackles a problem matters as much as what you want it to produce.

Methods for guiding AI process:
- **General guidance** (manual-style): high-level principles to apply
- **Step-by-step instructions** (cookbook-style): ordered procedure to follow
- **Demonstration** (example-style): "here is how I would do it"

Useful questions to prompt process thinking:
- What data or sources should the AI draw on?
- Is there a specific order of issues to address?
- Is there a particular analytical style or workflow to use?

### 3. Performance Description — Shape AI Behavior
AI tools are interactive systems that behave differently depending on context. Define the behavioral mode you need before starting.

Behavioral axes to consider:

| Dimension | Options |
|-----------|---------|
| Exploration vs. convergence | Explore multiple possibilities ↔ narrow to a specific answer |
| Challenge vs. alignment | Challenge assumptions ↔ follow your lead |
| Detail vs. brevity | Verbose explanation ↔ concise answer |
| Reasoning transparency | Show reasoning ↔ just give the answer |

Deciding your behavioral needs before the conversation starts turns a generic assistant into a finely tuned thinking partner.

## Key Insight

All three elements work together. Product description defines the target; process description shapes the path; performance description sets the interaction style. Together they transform raw AI capability into outputs tailored to your specific situation.
