## Summary

Upskilling improves performance in a current role while reskilling prepares someone for a different role, and AI adoption makes workforce plans need both. The guide offers a four-question test per role and a combined structure of shared foundation, role-based tracks, a selective reskilling cohort, and a manager layer. Each path is measured with different outcomes.

## Core Concepts

- [[Upskilling]]: adding or updating skills for the current role, typically weeks in short modules.
- [[Reskilling]]: building a new skill set for a different role, typically months with a transition period.
- [[Generative AI]]: reshaping tasks across functions at once, causing some roles to absorb change and others to shrink.
- [[Workforce Planning]]: HR and area leaders decide the path by role, with employee input.
- [[Corporate Training]]: usually cheaper than external hiring once recruiting, ramp-up and lost knowledge are counted.
- [[AI Literacy]]: the shared foundation layer for all employees.

## Key Takeaways

- **Different Problems**: Upskilling fixes performance in a role; reskilling prepares for a new one.
- **Four-Question Test**: Task change, internal destination role, skill gap distance, and employee desire.
- **Destination First**: No named target role means you are not ready to reskill.
- **Adjacent Moves**: Smaller skill gaps mean faster, safer transitions.
- **Combined Structure**: Shared foundation, role tracks, selective cohort, manager layer.
- **Reskilling Needs**: Protected time, real projects, mentor, transition plan, checkpoints.
- **Separate Metrics**: Upskilling tracks adoption and time saved; reskilling tracks moves and retention.

## 🧠 Core Principles

**T1. Match the intervention to the type of change** — If most of a role's tasks are sped up but still needed, improve the person in the role; if tasks are replaced and headcount isn't justified, move the person to a different role.
→ explains: Four-Question Test, Different Problems

**T2. A transition needs a destination** — Retraining people for roles that do not exist or are unconfirmed fails, so demand must be verified before enrolment.
→ explains: Destination First, Reskilling Needs

## 🃏 Review Questions

**Q1**: What is the difference between upskilling and reskilling?
**A**: Upskilling adds or updates skills so someone does their current job better; reskilling builds a new skill set for a different role, usually because the current one is shrinking or being automated.

**Q2**: What are the four questions for deciding which path a role needs?
**A**: How much of the work is changing, whether an internal role needs people, how close the person's skills are to the target, and what the person wants.

**Q3**: How should an organization structure a combined program?
**A**: Provide a shared AI foundation, role-based upskilling tracks, a small selective reskilling cohort with a named target role and mentor, and a manager layer to redesign and review work.
