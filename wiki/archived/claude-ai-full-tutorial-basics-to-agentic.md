## Summary

This tutorial maps [[Claude]] (by [[Anthropic]]) as a three-tier ecosystem — beginner chat features, extended power-user capabilities, and fully agentic tools — giving users a clear progression path from free to paid usage. The key distinction drawn is that Claude is an AI safety-focused model, making it less prone to confident wrong answers than competitors. At the agentic tier, Claude moves from answering questions to autonomously executing multi-step tasks on files, codebases, and the user's own computer.

## Core Concepts

- **[[Claude]] models**: [[Haiku]] (fast, lightweight), [[Sonnet]] (everyday workhorse, 80% of use cases), [[Opus]] (deep reasoning, complex tasks).
- **Tier 1 — Beginner features**: Chat, [[Web Search]] toggle, [[Artifacts]] (interactive output panel), [[Memory]] (global cross-conversation context), [[Claude Projects]] (scoped workspaces with custom instructions), [[Custom Style]] (persistent writing style preferences).
- **Tier 2 — Extended capabilities**: [[Connectors]] (live bridges to Gmail, Drive, Slack, Notion, etc.), [[Claude Skills]] (reusable capability modules for repeated workflows), [[Extended Thinking]] (step-by-step reasoning mode for complex problems), [[Research Mode]] (autonomous multi-source web research, 5–45 min per task).
- **Tier 3 — Agentic tools**: [[Claude Co-work]] (desktop app, works autonomously through local file folders), [[Claude Code]] (terminal/editor agent that reads codebases and writes/debugs code), [[Computer Use]] (Claude controls screen, cursor, and apps directly).
- **Pricing**: Free (Tier 1 with usage limits), Pro $20/mo (Tiers 2–3), Max $100–$200/mo (heavy/agentic workloads).

## Key Takeaways

- **Three-tier model**: most users only reach Tier 1; Tier 3 is where Claude acts as an autonomous worker.
- **Safety distinction**: Anthropic's safety focus makes Claude more honest about knowledge gaps vs. competitors.
- **Memory import hack**: paste memory from ChatGPT directly into Claude's memory system to transfer context.
- **Skills = reusable workflows**: build once, run repeatedly; separates casual from power users.
- **Extended Thinking**: noticeably better outputs for strategic, financial, or multi-step reasoning tasks.
- **Research Mode vs. Web Search**: Research Mode is autonomous multi-source investigation (5–45 min), not a single query.
- **Claude Code**: reads full codebase context before editing; useful even for non-developers automating with scripts.
- **Computer Use**: most reliable for structured, predictable, repeatable tasks with defined outcomes.
- **Connectors directory**: full list at `claude.ai/directory`; highest ROI integrations connect to where your actual work lives.
- **Upgrade advice**: start free → hit limits → move to Pro ($20) → hit Pro limits → consider Max ($100+).
