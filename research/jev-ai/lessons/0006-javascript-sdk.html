The JavaScript/TypeScript SDK

Module 2 Lesson 6 of 12 ~15 min
Learning objective Install and use the @typesafe-ai/sdk package to call the Jev API from TypeScript, and understand how the helper functions choice(), score(), and noul() differ from their Python counterparts.
Source
github.com/typesafe-ai/typesafe-sdk-js — Official JavaScript/TypeScript SDK repository with full examples, ESM/CJS builds, and TypeScript declarations.

Setup

The @typesafe-ai/sdk package requires Node.js version 20 or higher. If you are running an earlier Node version, upgrade before installing — the package ships modern ESM and may fail silently on older runtimes.

Install the package from npm:

npm install @typesafe-ai/sdk

Set your API key as an environment variable. The client reads it automatically — no need to pass it explicitly:

export TYPESAFE_API_KEY="your-api-key-here"

Unlike the Python SDK, the JavaScript client does not use a context manager. Instantiate it once and reuse it freely across your application:

import { choice, score, noul, TypeSafeClient } from "@typesafe-ai/sdk";

const client = new TypeSafeClient();

The package ships as ESM, CommonJS, and TypeScript declarations, so it works with any modern Node.js module system — whether you use import, require, or ts-node.

The Helper Functions

The JS/TS SDK defines questions using three helper functions — choice(), score(), and noul() — rather than class constructors. The names mirror the Python classes but are lowercase, consistent with JavaScript convention:

  • choice(prompt, options) — asks the model to pick one of the provided keys. Pass an object with each candidate key mapped to null.
  • score(prompt, { min, max }) — asks for a numeric rating on a defined scale.
  • noul(prompt) — asks for a yes/no/unclear judgment. The name stands for No, Unclear, Likely.
TypeScript infers the answer type directly from your question definition. Define choice() with keys billing, technical, and other, and the compiler automatically types response.answers.category.choice as "billing" | "technical" | "other" — no manual annotation needed. A misspelled answer key becomes a compile-time error before the code ever runs.

Full TypeScript Example

The following script classifies a support ticket by category and urgency, then checks whether it needs immediate escalation:

import { choice, score, noul, TypeSafeClient } from "@typesafe-ai/sdk";

const client = new TypeSafeClient();
const response = await client.systemOne({
  state: { document: "I was charged twice. Please fix this ASAP." },
  questions: {
    category: choice("What is this ticket about?", {
      billing: null,
      technical: null,
      other: null,
    }),
    urgency: score("How urgent? 0=low, 5=critical", { min: 0, max: 5 }),
    needsEscalation: noul("Does this need immediate escalation?"),
  },
});

// TypeScript knows this is "billing" | "technical" | "other"
console.log(response.answers.category.choice);
console.log(response.answers.urgency.score);

Answers are accessed with dot notation: response.answers.<key>.<primitive>. The response object is fully typed — your IDE will autocomplete answer keys and primitive field names.

Python vs JavaScript — Side by Side

The same API call looks slightly different in each SDK. The table below maps every major syntax difference, one row per operation:

Operation Python SDK JS/TS SDK
Import from typesafe_sdk import TypeSafeClient, Choice import { TypeSafeClient, choice } from "@typesafe-ai/sdk"
Instantiate with TypeSafeClient() as client: — context manager required const client = new TypeSafeClient(); — no context manager
Call method client.system_one({...}) — snake_case, synchronous await client.systemOne({...}) — camelCase, async
Choice question Choice("prompt", {"a": None, "b": None}) — class constructor choice("prompt", { a: null, b: null }) — helper function
Answer access response.answers["category"].choice — bracket notation response.answers.category.choice — dot notation, typed
Async handling Synchronous call — blocks until complete await required — the method is always async

Lesson summary
  • Install with npm install @typesafe-ai/sdk; Node.js 20 or higher is required.
