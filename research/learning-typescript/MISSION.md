# Mission: Learning TypeScript

## Why
You have years of Java experience and a foundation in JavaScript — the hard part is not learning a new syntax, it is unlearning a set of deeply-held type system assumptions. TypeScript's structural, compile-time-only type system operates differently enough from Java that applying Java instincts directly leads to bugs, confusion, and over-engineered code. This course rebuilds your mental model from the ground up so you can write idiomatic, type-safe TypeScript for real frontend and Node.js projects.

## Success looks like
- You can read any TypeScript codebase and understand what every type annotation means without guessing
- You can explain structural vs nominal typing and identify when it changes your code decisions
- You write TypeScript without reaching for `any` or disabling strict mode to silence errors
- You set up a TypeScript project from scratch with the right tsconfig and tooling for Node.js or React
- You can decode TypeScript error messages and know which compiler option or type fix to apply
- You recognise and avoid the top Java-developer TypeScript pitfalls without a checklist

## Constraints
- Learning from the official TypeScript Handbook and community resources — no proprietary systems required
- Self-paced, one lesson at a time
- All examples assume strict mode is enabled

## Out of scope
- TypeScript compiler internals or contributing to the TypeScript codebase
- Angular or Vue-specific TypeScript patterns
- Advanced type-level programming beyond utility types and basic inference
- Runtime type validation libraries (Zod, io-ts)
