# Mission: IBM Carbon Design System

## Why
Carbon is IBM's production design system powering every IBM digital product. Learning it means you can build accessible, consistent, professional-grade UIs without designing from scratch — letting you ship faster and collaborate with any team already using Carbon. The outcome is a working React application built entirely with Carbon components, styled with tokens, and laid out on the 2x grid.

## Success looks like
- Install `@carbon/react` and configure Sass correctly in a Next.js project from memory
- Apply the right button variant (primary, secondary, ghost, danger) for any given context
- Build a responsive two-column layout using `<Grid>` and `<Column>` with correct breakpoint props
- Override Carbon's theme by editing tokens in Sass — without touching component source
- Identify and fix a WCAG contrast failure in a Carbon-based UI using Carbon's accessibility tools
- Write a UI label that follows IBM's voice guidelines (verb+noun, sentence case, no truncation)

## Constraints
- Learning from documentation and source material — no access to a live Figma license or IBM internal tooling
- Self-paced, one lesson at a time

## Out of scope
- Carbon for Angular, Vue, or Svelte (focused on React)
- Data visualization components (`@carbon/charts`)
- AI Label and experimental components
- Carbon Web Components framework
