# Mission: Blue Team vs Red Team in Cybersecurity

## Why
Building LLM-powered security tools requires knowing exactly what offensive and defensive practitioners do — not in the abstract, but at the level of specific phases, tools, and decision points. Understanding both playbooks (and the frameworks that connect them) lets you scope what to automate, what to leave to humans, and where the highest-leverage LLM interventions exist.

## Success looks like
- Can map a real or fictional breach to its Cyber Kill Chain phases and identify where detection should have fired
- Can name the primary tools for each team (Nmap, Metasploit, Burp Suite vs Elastic SIEM, EDR, threat intel platforms) and explain why each one exists
- Can explain purple teaming and use ATT&CK technique IDs to frame a measurable coverage gap
- Can describe the PentestGPT and PyRIT architectures and sketch a comparable LLM harness for a self-serve security check
- Can distinguish which security tasks are LLM-automatable vs. which require irreplaceable human judgment

## Constraints
- Learning from sourced research — no access to live lab environments
- Self-paced, one lesson at a time

## Out of scope
- Hands-on tool installation and configuration (Metasploit lab setup, Elastic SIEM deployment)
- Compliance and regulatory frameworks (SOC 2, ISO 27001, PCI-DSS)
- Cloud-native security architecture (IAM, cloud CSPM)
- Malware analysis and reverse engineering
