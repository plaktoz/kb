The structure, where a chip supplier underwrites its own customer's ability to buy its chips, draws uncomfortable parallels to vendor-financing cycles in the dot-com telecom buildout.

- **[Bun rewrote 535,000 lines of Zig in Rust in 11 days using 64 parallel Claude Code agents](../../wiki/technology/rewriting-bun-in-rust.md)**: The Bun team ran implementer-agent/adversarial-reviewer loops that peaked at 1,300 lines/min, fixed 128 known bugs, cut binary size ~20%, and eliminated an unbounded memory leak — at an API cost of ~$165K versus a projected year of human engineering. The key insight: treat 16,000 compiler errors as a divisible task list for parallel agents, not as a barrier.

- **[Simon Willison: hoard working code examples so agents can combine them instantly](../../wiki/technology/hoard-things-you-know-how-to-do.md)**: A personal archive of proven, running code snippets becomes an agent force-multiplier — you can prompt an agent with two known solutions and get a novel combination in minutes rather than researching from scratch. The pattern scales further when agents can clone your own repos as reference material.

- **[Subagents are context-budget management, not just task delegation](../../wiki/technology/agentic-engineering-subagents.md)**: Claude Code's "Explore" subagent illustrates the pattern: dispatch a fresh context window for token-heavy investigation, return only the condensed summary, and preserve the parent agent's limited budget for actual decisions. Parallel subagents on cheaper, faster models (Haiku) can further compress wall-clock time on independent file edits.

- **[Ask your coding agent to build interactive explanations of its own code to pay down cognitive debt](../../wiki/technology/agentic-engineering-interactive-explanations.md)**: Animated, interactive artifacts can unlock understanding of non-obvious algorithms where prose walkthroughs fail — illustrated by a word-cloud placement algorithm that only clicked after being visualized as an animated spiral search. The practical rule: any core logic you couldn't explain to someone else is cognitive debt accumulating interest.

- **[Agents can and should manually test their own code — passing unit tests aren't enough](../../wiki/technology/agentic-manual-testing.md)**: Coding agents that can execute code should be explicitly directed to run it, hit real APIs, and drive a browser via Playwright — because generated code should be assumed broken until actually run, and automated test suites routinely miss startup crashes, missing UI elements, and edge-case failures outside their coverage.

- **[Harmony raised $34M at seed to replace IT-ticket workflows with a Slack-native AI agent](../../wiki/technology/harmony-ai-agent-workplace-it-tickets.md)**: Founded by the team that sold Epsagon to Cisco for $500M, Harmony's agent handles IT, HR, and onboarding requests inside Slack and Microsoft Teams with role-based permissioned actions, integrating 100+ enterprise applications. - **[Forbes AI 50 2026: Anthropic hit $4.5B revenue, Claude surpassed ChatGPT downloads, and the Pentagon blacklisted them anyway](../../wiki/technology/forbes-ai-50-2026-list.md)**: The list captures a polarizing year — Anthropic is the most-downloaded app on the App Store and valued at $380B, while vertical AI companies like EliseAI (80%+ of large U.S. property managers) and Gamma (profitable since 2023) demonstrate that narrow application beats general platform for revenue durability.

### 🧠 Learning

- **[People forget 70% of new material within 24 hours — and rereading is actively making it worse](../../wiki/learning/how-to-learn-faster-and-better-science-backed.md)**: Ten evidence-based techniques anchored in the Spacing Effect, Testing Effect, and Cognitive Load Theory reliably improve retention without requiring more total study time. The costliest mistake is passive review (rereading, highlighting): it produces recognition, not recall, which is exactly the wrong kind of memory for durable knowledge work.

- **[Information Processing Theory: how sensory memory → working memory → long-term memory shapes everything about effective instruction](../../wiki/learning/information-processing-theory-cognitive-stages.md)**: Working memory holds roughly seven items at once, making chunking and scaffolding non-optional for any learning design — content that doesn't chunk loses learners regardless of how "important" it is. The framework connects directly to spaced repetition and adaptive quizzing tools, and its computer-metaphor limits (emotion, parallel processing) are worth keeping in mind when applying it mechanically.

### ❤️ Health

- **[SuperAgers have no meaningful genetic advantage over average older adults — exceptional memory isn't inherited low Alzheimer's risk](../../wiki/health/superagers-genetics-do-not-explain-cognitive-resilience.md)**: A University of Chicago study of 142 adults in their 80s–90s with memory matching people decades younger found no APOE or polygenic Alzheimer's risk-score difference from cognitively average peers. Exceptional late-life cognition appears to require an active protective mechanism distinct from simply lacking known risk factors — research now turns to imaging, blood biomarkers, immune profiling, and sleep data.

- **[Diet quality predicts cardiometabolic risk — not how processed the food is](../../wiki/health/diet-quality-versus-food-processing-level-study.md)**: A Harvard-led 40-year study of 200,000+ adults found healthy diets lowered risk and unhealthy diets raised it regardless of processing level within each quality tier, challenging the blanket "avoid ultra-processed foods" heuristic. A healthy plant-based diet that includes some processed foods still outperforms an unhealthy "minimally processed" diet — nutrient density is the primary lever.

- **[A blood test measuring ESAT-6 can distinguish active TB from latent infection without a sputum sample](../../wiki/health/tuberculosis-blood-test-esat6-biomarker.md)**: Presented at ADLM 2026, the test showed a clear stepwise signal across infection stages (uninfected → latent → active TB) and outperformed two existing blood-based markers — important because a quarter of the world carries TB bacteria and many early-stage patients can't produce a sputum sample for current diagnostics.

- **[Brain-training apps don't improve overall memory — lifestyle interventions do](../../wiki/health/how-to-improve-memory-brain-health-tips.md)**: Neuroplasticity means the brain forms new neural connections at any age, but commercial brain-training apps mostly improve only the specific task practiced. Physical exercise, 7.5–9 hours of sleep, stress management, and social connection (Harvard study: most socially active adults had the slowest memory decline) are the reliably effective levers, alongside treating underlying health conditions that commonly masquerade as memory loss.

## 🧠 Emerging Connections

The Bun rewrite ([rewriting-bun-in-rust](../../wiki/technology/rewriting-bun-in-rust.md)) used **adversarial reviewer agents** who saw only the diff and were told to assume it was wrong — a structural parallel to the Staff Work series' core argument that a paper should be read as both the approver *and* the person who must carry it out ([staff-work-part-1-frame-the-issue](../../wiki/productivity/staff-work-part-1-frame-the-issue.md)). Both are instances of the same design principle: the person generating the work is the worst-positioned party to verify it, so you need a structurally separate reviewer who starts from skepticism rather than familiarity. In the Bun case the reviewer was a separate agent; in staff work it's [[Inversion]] — the author deliberately inhabiting the approver's perspective before submission. The same adversarial separation that caught a `trunc()`-vs-`floor()` memory bug also underpins what makes a decision memo trustworthy enough to act on.
