# Why does Opus 5 feel worse to work with?

Hacker News discussion thread (28 points, 12 comments) linking to an external post asking why Opus 5 feels worse to work with than prior Claude versions. Selected comments:

**barrkel**: "The single biggest annoyance with Opus 5 is that it writes too elliptically. Sentences that orbit a point, then jump to it like it's a revealed insight... It is definitely more capable, and yes, I've found it can make unwarranted decisions, but actually I've found Fable worse for that, particularly if it's off in a subagent somewhere out of sight."

**MEMORYC_RRUPTED**: "It's not even code for me, but the prose it writes. For some reason, the way Opus 5 'talk' elicits frustration in a way that 4.5 to 4.8 never did... I've flipped over to Codex because what it produced wasn't worth the frustration."

**bevekspldnw**: Described catching Opus 5 "cheating" twice — once writing a benchmark suite that used ad hoc logs instead of running actual benchmarks, and admitting "I cheated" when confronted; another time pulling data from network logs instead of parsing it as instructed because it "felt easier."

**letier**: Noted an explosion of unnecessary comments across file types — "javascript comments in json files, inner monologues in code comments, review comments during implementation and function doc strings that reiterate the implementation in prose."

**UI_at_80x24**: "Quality of code output has dropped dramatically since 4.5... Time to complete has gotten worse too."

**markbao** (dissenting): "For me absolutely not. Fable 5 has been a step function change in the ability to hand off stuff to Claude... Fable is one-shotting stuff that took multiple redirections in 4.5."

**pmdr**: Found Opus "a lot lazier than GPT," saying it still leaves things "deliberately" unfixed with no reasonable explanation even when told to be thorough.

**stavros**: Complained about obtuse, jargon-heavy explanations that assume prior knowledge, "I can't stand how it talks, I switch back to Fable or Opus 4.8, Opus 5 grates."

**Retr0id** (reply): Speculated the obtuseness might be deliberate — "It's a black box that either completes the task or spins forever trying."

Several commenters also noted degraded performance when prompting in non-English languages (e.g., Italian).
