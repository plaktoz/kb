# PyG (PyTorch Geometric) Documentation

## Summary

PyG is a PyTorch-based library for building and training Graph Neural Networks (GNNs) on structured data. It implements methods from published research in "geometric deep learning" and supports both small graph batches and large single graphs.

## Key Features

- Deep learning methods for graphs and irregular structures
- Mini-batch loaders for various graph scales
- Multi-GPU support
- `torch.compile` and DataPipe compatibility
- Benchmark datasets with customizable interfaces
- Transforms for graphs, 3D meshes, and point clouds
