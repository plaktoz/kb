# Microsoft is limiting Microsoft 365 & OneDrive on Windows 10 to push holdouts to Windows 11

Microsoft is making Windows 10 less appealing to holdouts by limiting Microsoft 365 and OneDrive, with Microsoft 365-related changes beginning to roll out in August 2026. Microsoft 365 version 2608, covering all Office apps and Copilot, will be the last major release for Windows 10 — users will be asked to move to Windows 11 for new features.

Microsoft has pledged support for Office apps on Windows 10 until at least October 10, 2028, and there's no indication that will be extended. In a support document, Microsoft noted: "Devices running Microsoft 365 Apps on Windows 10 will receive feature updates and Copilot support (where eligible) until Version 2608 is released. Devices will remain on Version 2608, receiving only security updates until October 10, 2028." Version 2607 was released on August 11, with version 2608 expected in two weeks. Office apps for Windows 10 are now officially in a "frozen development" state.

Most major new Office features recently have centered on Copilot or Microsoft's agents — for example, PowerPoint's April update added Copilot-based presentation editing, and a February update added agent support in Word. Otherwise, Office apps are largely feature-complete, and most enterprises and consumers are already satisfied with the current feature set.

## What about OneDrive for Windows 10?

OneDrive will not stop working on Windows 10 as long as users run the most recent version of the OS. Microsoft plans to retire support for older versions of Windows released before Windows 10 22H2, though most users are already on 22H2. Per Microsoft's documentation: "Devices running the OneDrive desktop app on Windows 10 22H2 will continue to receive updates through October 10, 2028. On devices running an older version of Windows 10, the OneDrive desktop app will no longer update." Major new OneDrive features going forward are less certain even for 22H2 users.

## Windows 10 holdouts remain stubborn

According to HP, three in ten PCs still use Windows 10, and an IT management company estimates Windows 10 holds approximately 17% market share, with Windows 11 adoption slowing. Microsoft has also admitted that Windows 10's end of support is no longer driving Windows 11 sales as strongly as it did last year. Many holdouts either find Windows 10 works fine for their needs or lack a compelling reason to upgrade hardware just to run Windows 11, especially as PC prices have nearly doubled.
