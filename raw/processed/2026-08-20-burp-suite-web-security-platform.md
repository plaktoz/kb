# PortSwigger – Burp Suite Web Security Platform

PortSwigger offers Burp Suite, described as "the world's #1 web penetration testing toolkit," along with several related products for web application security.

## Key Products

- **Burp AT** – Agentic AI extending human-led pentesting
- **Burp Suite Professional** – Manual/hands-on pentesting toolkit for security professionals
- **Burp Suite DAST** – "Enterprise-enabled dynamic web vulnerability scanner" for AppSec teams; supports automated and CI-driven scanning
- **Burp Suite Community Edition** – Free entry-level tools for beginners

## Main Use Cases

| Audience | Purpose |
|---|---|
| Pentesters | Hands-on vulnerability discovery and exploitation |
| AppSec/Vuln Management | Scalable automated DAST scanning |
| DevOps/Engineering | CI-integrated scanning to catch issues before production |
| Learners | Free Web Security Academy training |

## Covered Vulnerability Types

XSS, SQL injection, CSRF, XXE, directory traversal, SSRF, and more.

## Summary

PortSwigger provides a range of security testing tools spanning manual pentesting, enterprise automation, and developer-integrated scanning, complemented by free educational resources.
