## About the OWASP GenAI Security Project

A global open-source initiative focused on identifying and mitigating risks in generative AI, including LLMs and agentic systems. The community has grown to include 600+ contributors from 18+ countries and nearly 8,000 members.

## Historical v1.1 Top 10 List (2023, Archived)

| ID | Vulnerability |
|----|--------------|
| LLM01 | **Prompt Injection** — crafted inputs lead to unauthorized access/data breaches |
| LLM02 | **Insecure Output Handling** — unvalidated outputs enable downstream exploits |
| LLM03 | **Training Data Poisoning** — tampered data compromises model behavior |
| LLM04 | **Model Denial of Service** — resource-heavy operations cause disruptions |
| LLM05 | **Supply Chain Vulnerabilities** — compromised components undermine integrity |
| LLM06 | **Sensitive Information Disclosure** — unprotected outputs expose sensitive data |
| LLM07 | **Insecure Plugin Design** — insufficient access controls risk remote code execution |
| LLM08 | **Excessive Agency** — unchecked LLM autonomy causes unintended consequences |
| LLM09 | **Overreliance** — uncritical use of LLM outputs leads to poor decisions |
| LLM10 | **Model Theft** — unauthorized access risks theft of proprietary models |
