# Neo4j

Source: https://en.wikipedia.org/wiki/Neo4j
Scraped: 2026-08-03

## Overview

Neo4j is a graph database management system (GDBMS) built in Java, developed by Neo4j, Inc. — a global graph intelligence company. It uses the **Cypher query language** and supports connectivity via a transactional HTTP endpoint or the binary "Bolt" protocol.

---

## History

- **Founded:** 2007 in Sweden by Emil Eifrem, Johan Svensson, and Peter Neubauer
- The concept originated from a napkin sketch Eifrem made on a flight in 2000
- Originally called "Project Neo"; the name Neo4j combines "Neo" (new) with "4j" (for Java)
- Headquarters relocated to **San Mateo, California** in 2011; engineering hub stayed in Sweden
- **2016:** Used to analyze the Panama Papers leak
- **2017:** NASA acknowledged Neo4j's role in recovering Apollo program data
- **2024:** Revenue surpassed $200 million; valued at $2.2 billion
- **2025:** Announced $100M investment in generative AI; launched agentic AI offerings
- **2026:** Acquired GraphAware, an intelligence analysis software provider

## Data Structure

Neo4j stores three core elements:
1. **Nodes** — entities in the graph
2. **Edges** — connections between nodes
3. **Attributes** — properties of nodes and edges

Both nodes and edges can carry labels, which enable narrowed searches. Schema-based indexing was introduced in version 2.0.

---

## Technical Details

- Implemented in **Java**
- **ACID-compliant** transactional database
- Native graph storage and processing
- Query language: **Cypher**
- Communication: HTTP endpoint or binary **Bolt** protocol
- Neo4j contributed to the **ISO-standardized Graph Query Language (GQL)**
- Founding member of the **GraphQL Foundation** (under the Linux Foundation)

## Criticisms

- Researcher Andy Pavlo (Carnegie Mellon) questioned the move away from the relational model
- CWI researchers benchmarked a modified **DuckDB** against Neo4j and found it outperforms Neo4j on certain graph tasks
- Neo4j pursued legal action against PureThink over license modifications; a 2024 court ruling imposed **$597,000 in actual damages** on PureThink for DMCA violations and trademark infringement
