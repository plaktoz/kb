# GSQL: Graph Query Language | TigerGraph

## Overview

GSQL® is TigerGraph's query language designed for fast, scalable graph operations and analytics, available for cloud or on-premises deployments.

## Key Features

- **Schema-Based** architecture
- **Built-in High Performance Parallelism** for fastest results
- **SQL-Like syntax** familiar to over a million users
- **Conventional Control Flow** (FOR, WHILE, IF/ELSE) for implementing standard algorithms
- **Procedural Queries** — parameterized queries that can call other queries for complex operations
- **Transactional Graph Updates** — supports HTAP (Hybrid Transactional/Analytical Processing) with real-time data updates

## SQL Compatibility

GSQL builds on SQL's foundation, leveraging relational algebra's proven robustness. Its SQL-like syntax reduces the learning curve for existing SQL developers.

## Industry Vision

TigerGraph positions GSQL as a new standard for graph query languages, combining the best elements of prior relational and graph query approaches. TigerGraph has published a vision for extending GSQL to support "simultaneous querying of graph and relational data" that highlights commonalities between the two data models.
