# How to Build an Adaptive AI Tutor for Any Course Using Knowledge Graph-Enhanced Retrieval-Augmented Generation (KG-RAG)

source_url: https://arxiv.org/abs/2311.17696

---

**Authors:** Chenxi Dong, Yimin Yuan, Kan Chen, Shupei Cheng, Chujie Wen

**Submitted:** November 29, 2023 (v1); last revised February 12, 2025 (v7)

**Published in:** ICEIT 2025

**Abstract:**

The paper tackles two major challenges when deploying LLMs in Intelligent Tutoring Systems: keeping responses factually accurate and maintaining context-aware instruction. Standard RAG falls short in educational settings because it relies purely on semantic similarity, missing deeper conceptual relationships between topics.

The authors propose KG-RAG, which merges structured knowledge graphs with context-aware retrieval. Three core contributions are highlighted:

1. An architecture grounding AI responses in structured domain knowledge
2. Empirical validation via controlled experiments (n=76) showing a "35% increase in assessment scores, p<0.001"
3. A practical deployment framework for real-world implementation

The framework is designed to be adaptable across diverse educational subjects and contexts.
