# htmx 4.0.0 is Released

htmx 4.0.0 has been released after 8 months of development. The project originated when the lead developer built fixi and grew familiar with the `fetch()` API, then collaborated with contributors Christian, Michael, and Alex to modernize the library.

Note: htmx 4 will remain tagged `next` on NPM rather than `latest` until early 2027, to avoid breaking users on unversioned CDN URLs.

## Major Changes

**Attribute Inheritance** — Now explicit by default. In htmx 2, attributes like `hx-confirm` were silently inherited by child elements. In htmx 4, you must append `:inherited` to opt in:

```html
<div hx-confirm:inherited="Are you sure?">
```

A CLI upgrade checker is provided to find affected code.

**Event Renaming** — Events now follow a `htmx:phase:action` pattern (e.g., `htmx:beforeRequest` → `htmx:before:request`). XHR events are removed; most error events consolidate into `htmx:error`.

**History** — No longer caches snapshots in `localStorage` by default (a frequent source of bugs). Back-navigation now re-fetches pages. An `hx-history-cache` extension using `sessionStorage` is available for those wanting local caching.

## New Features

- **Morphing swaps** — Built-in DOM morphing (evolved from idiomorph) is now included natively.
- **`<hx-partial>` tag** — A cleaner alternative to out-of-band swaps for targeting multiple elements in one response.
- **New extensions** — Including `hx-preload`, `hx-download`, `hx-alpine-compat`, updated streaming extensions (`hx-sse`, `hx-ws`, `hx-multipart`), and `hx-live`, described as a lightweight front-end scripting solution inspired by Alpine.js, jQuery, and hyperscript.
- **`htmax.js` bundle** — Packages htmx with the most popular extensions in a single file.

## Installing

```html
<script src="https://unpkg.com/htmx.org@4.0.0/dist/htmx.min.js"></script>
```

## Upgrade Tool

```bash
npx htmx.org@4.0.0 upgrade-check -- ./templates
```

htmx 2 will continue to receive support indefinitely; upgrading is not urgent.
