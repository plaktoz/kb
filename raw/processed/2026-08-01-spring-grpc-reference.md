# Spring GRPC :: Spring gRPC Reference

source_url: https://docs.spring.io/spring-grpc/reference/index.html

---

The Spring gRPC project aims to streamline the development of gRPC applications within the Spring ecosystem.

**Documentation Sections:**
- Getting Started — Shows how to create your first gRPC application.
- Server Section — Provides a high-level overview of gRPC servers and their representation in Spring gRPC.
- Client Section — Covers gRPC clients. A gRPC application can function as both a client and a server simultaneously.
- What's New? — Release notes and updates.

**Available Versions:**
- Stable: 1.0.3
- Snapshot: 1.1.1-SNAPSHOT
- Snapshot: 1.0.4-SNAPSHOT
