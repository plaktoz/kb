# gRPC-Spring-Boot-Starter Documentation

source_url: https://yidongnan.github.io/grpc-spring-boot-starter/en/

---

This library combines Google's open-source high performance RPC-framework with Spring Boot's ease of setup. It simplifies gRPC server/client configuration by requiring only a single dependency and a single annotation on service classes or client stub fields.

**Documentation Sections:**

Server: Getting Started, Configuration, Exception Handling, Contextual Data/Scoped Beans, Testing, Events, Security

Client: Getting Started, Configuration, Security, Testing with gRPC Stubs

Additional Topics: Troubleshooting, Examples, gRPC-Java Flavors, Version Overview, Actuator/Metrics, Brave Tracing/Spring Cloud Sleuth, Kubernetes Setup, Benchmarking, and Contributing
