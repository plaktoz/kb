# MITRE ATT&CK® Enterprise Matrix

MITRE ATT&CK is a globally-accessible knowledge base of adversary tactics and techniques based on real-world observations. It serves as a foundation for threat modeling across private sector, government, and cybersecurity communities, available free of charge.

## Enterprise Matrix Structure

The matrix organizes adversary behavior into 15 tactics:

| Tactic | Techniques |
|--------|-----------|
| Reconnaissance | 12 |
| Resource Development | 9 |
| Initial Access | 11 |
| Execution | 20 |
| Persistence | 22 |
| Privilege Escalation | 13 |
| Stealth | 30 |
| Defense Impairment | 18 |
| Credential Access | 17 |
| Discovery | 34 |
| Lateral Movement | 9 |
| Collection | 17 |
| Command and Control | 18 |
| Exfiltration | 9 |
| Impact | 15 |

Each tactic contains numbered techniques and sub-techniques covering the full adversary lifecycle from initial reconnaissance through final impact.
