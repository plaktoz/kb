# Claude Code for Product Managers

**Author:** Marcus Moretti
**Date:** May 1, 2026
**Source:** Every

Moretti, general manager of Spiral (Every's AI writing tool), describes operating as a solo "two-slice team" responsible for code, support, marketing, and product management — all enabled by Claude Code.

**Roadmap & Tickets:** He wrote only one product document himself — the roadmap. From that, Claude generated ~100 detailed tickets via GitHub CLI, each with context, acceptance criteria, and implementation notes. A custom `/prioritize` command keeps the backlog continuously sorted.

**Monitoring:** Instead of dashboards, he runs a `/pulse` command that delivers an analyst-style briefing — surfacing metrics, grading conversations, and flagging anomalies in plain English. Bug fixes can happen in the same chat thread where issues surface.

**Research:** Using the Arxiv MCP, Claude helped him survey academic literature on stylometry, directly informing Spiral's style-transfer feature development.

**On SaaS survival:** He believes products survive by owning unique data sources and offering seamless agent integrations. Products lacking MCP support were cancelled from his stack.

His conclusion: eliminating busywork creates space for creative thinking. As he puts it, "product management can now be fun."
