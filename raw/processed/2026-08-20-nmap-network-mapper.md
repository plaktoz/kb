# Nmap: Network Mapper

Nmap is a free, open-source utility for network discovery and security auditing, used by administrators and security professionals worldwide.

## Key Features

- **Flexible** – Supports numerous port scanning techniques (TCP & UDP), OS detection, version detection, and ping sweeps
- **Powerful** – Capable of scanning networks with hundreds of thousands of machines
- **Portable** – Runs on Linux, Windows, macOS, FreeBSD, Solaris, and many others
- **Free & Open Source** – Available for download with full source code under the Nmap license
- **Well Documented** – Includes man pages, tutorials, whitepapers, and a full reference book
- **Popular** – Included in many OS distributions; thousands of daily downloads

## Included Tools

| Tool | Purpose |
|------|---------|
| **Zenmap** | GUI and results viewer |
| **Ncat** | Data transfer and debugging |
| **Ndiff** | Scan result comparison |
| **Nping** | Packet generation and analysis |

## Recognition

Named "Security Product of the Year" by Linux Journal, Info World, and others. Featured in films including *The Matrix Reloaded* and *Die Hard 4*.
