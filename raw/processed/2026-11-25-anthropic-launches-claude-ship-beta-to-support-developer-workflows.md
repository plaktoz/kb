# Anthropic launches Claude Ship beta to support developer workflows

Anthropic has launched Claude Ship, a new tool designed to support developers in reviewing and approving code changes more quickly.

The company announced that Claude Ship is now available in beta on Claude Team and Enterprise plans for repositories hosted on GitHub.

Claude Ship uses AI to automate several steps in the software development workflow.

The system can review pull requests (PRs), address feedback, fix problems, and determine which changes can be merged, based on rules defined by each team.

The aim, according to Anthropic, is to allow teams to move code to production at the same speed at which it is written.

The new product brings together three components: Code Review, which is generally available, and two new beta features called PR Steward and Claude Approvals.

Code Review examines proposed code changes against the existing codebase, offering findings at three review depths, which are Quick, Standard, or Deep.

PR Steward intervenes to resolve failing checks, merge conflicts, and feedback, but does not approve or merge PRs. Instead, it provides comments and assists in fixing identified issues.

Claude Approvals can make automated approval decisions according to policy files written by the development team for each repository.

The policy allows teams to specify when automation is permitted and when human approval remains necessary.

Anthropic said that the use of Claude Ship is billed according to tokens processed, with costs varying by the size and number of PRs, review level, and the amount of work handled by PR Steward.

Administrators have control over spend limits for Code Review and PR Steward.

Claude Ship is not currently available to organisations with a HIPAA configuration, Zero Data Retention, or customer-managed encryption keys.

Organisations on eligible Claude Enterprise plans can claim at least $10,000 in Claude Ship credits by 15 January 2027, to be used within 30 days of claiming.

Direct user access to Claude Ship is available either through a new /ship command for individual PRs, or by enabling it for entire repositories for automated operation.

The system does not eliminate the need for human oversight, as teams may require human sign-off for certain changes.

Claude Ship is being rolled out to users of Claude Code and the Claude desktop application.

Recently, Anthropic raised $81.3bn in what is said to be the largest initial public offering (IPO) on record, with its shares priced above the projected range and giving the company a fully diluted market valuation of around $1.5tn.
