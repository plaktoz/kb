# Copy Our Homework

This edition compiles workflows, prompts, and tips from the week's three Context Window issues under a "Steal these" format.

## Computer Use Highlights

- Staff shared tasks delegated to AI (calendar management, support chats, troubleshooting)
- Douglas Brundage's four-step deck workflow uses Codex to build Google Slides decks
- Randy Counsman uses a 🖥️ emoji signal to avoid disrupting Codex mid-task

## Folder/File Organization

- A prompt instructs agents to audit folder structures without moving files without approval
- Kieran Klaassen maintains one folder per job and separate memory files (daily/weekly/monthly/yearly)

## Token Spend

- An unbounded agent swarm consumed 4.5 billion tokens on one Blender model; the fix capped subagents at five and added a judge agent
- Marcus Moretti matches models to task complexity (Sonnet → basic checks, Opus → scoped changes, Fable 5.1 → large feature planning)
- Arielle Shipper's three post-experiment questions: cost, value gained, lessons learned

- Anthropic merged Chat and Cowork into one unified Claude product
