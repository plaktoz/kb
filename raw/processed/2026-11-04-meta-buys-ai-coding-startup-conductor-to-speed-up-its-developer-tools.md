# Meta buys AI coding startup Conductor to speed up its developer tools

What's the deal? Meta has acquired Conductor, a startup that builds software for running multiple AI coding agents in parallel. Financial terms were not disclosed. Conductor, founded in 2024 and led by chief executive Charlie Holtz and chief technology officer Jackson de Campos, raised a $22 million Series A from Spark and Matrix in March 2026.

What does Conductor do? Its platform lets engineers run several coding agents at once, each in an isolated workspace, then review, open pull requests for, and merge their work. It supports first-party agents including Claude Code, Codex, and Cursor, with developers using their own subscriptions and keys.

What's the endgame? People familiar with the deal say Conductor's fast product development and focus on developer experience are expected to support Meta's next generation of AI coding products.

Why now? Coding is becoming a key route to wider AI adoption and enterprise spending. Stronger performance in programming can also improve the underlying models, making developer tools both a market and a testing ground for more capable systems.

The signal: Meta's move places it in a widening contest to own the tools developers use. On the same day, OpenAI said it plans to acquire another developer tools startup — a sign of how fast AI companies are moving to lock up coding products and teams.
