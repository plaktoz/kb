# Knowledge Graph

A knowledge graph is a knowledge base using a graph-structured data model to represent entities and their relationships, encoding the "free-form semantics or relationships underlying these entities."

They are associated with:
- Linked open data projects (Semantic Web)
- Search engines (Google, Bing, Yahoo)
- Question-answering services (WolframAlpha, Siri, Alexa)
- Social networks (LinkedIn, Facebook)

Recent machine learning advances — particularly graph neural networks — have expanded their use into genomics, proteomics, and systems biology.

## History

- **1972** – Term coined by Austrian linguist Edgar W. Schneider
- **Late 1980s** – University of Groningen/Twente joint project on semantic networks
- **1985** – WordNet founded
- **2007** – DBpedia and Freebase launched
- **2012** – Google introduced its Knowledge Graph
- **2024** – Microsoft Research's GraphRAG integrated LLM-generated graphs into retrieval-augmented generation

## Key Concepts

**Definitions** vary, but common features include flexible entity relations, a general network structure, and support for ontology-based reasoning.

**Implementations** include YAGO, Wikidata, Neo4j, GraphDB, and personal knowledge graph tools.

**Virtual knowledge graphs** query underlying relational databases rather than storing data in specialized graph databases.

**Entity alignment** — identifying nodes across different graphs representing the same real-world entity — is an active research area, with LLMs showing promise since 2023.
