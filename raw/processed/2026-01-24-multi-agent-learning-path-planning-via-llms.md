# Multi-Agent Learning Path Planning via LLMs

source_url: https://arxiv.org/abs/2601.17346

---

**Authors:** Haoxin Xu, Changyong Qi, Tong Liu, Bohao Zhang, Anna He, Bingqian Jiang, Longwei Zheng, Xiaoqing Gu

**Submitted:** January 24, 2026

**Abstract:**

The paper introduces MALPP, a framework integrating LLMs into intelligent tutoring systems to improve personalized learning. It critiques existing methods for lacking "transparency, adaptability, and learner-centered explainability."

The system employs three specialized agents:
- Learner Analytics Agent — profiles the learner
- Path Planning Agent — generates tailored learning sequences
- Reflection Agent — iteratively refines paths with interpretable feedback

The framework is grounded in Cognitive Load Theory and the Zone of Proximal Development, ensuring recommendations are pedagogically sound.

Experiments on the MOOCCubeX dataset using seven LLMs demonstrated that MALPP "significantly outperforms baseline models in path quality, knowledge sequence consistency, and cognitive load alignment." Ablation studies confirmed the value of both the multi-agent collaboration and the theoretical constraints.
