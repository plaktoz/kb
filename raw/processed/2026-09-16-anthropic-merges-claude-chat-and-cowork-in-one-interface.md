# Anthropic merges Claude chat and Cowork in one interface

Anthropic has unified its Claude chat and Cowork interfaces into a single window, also incorporating Artifacts and Claude Design. The company noted that users previously struggled to choose the right tab for different tasks. The new system has Claude automatically routing requests, eliminating the need to manually switch between tabs.

New features include:

- **Presentations:** Users can create, edit, present, and export slides as PDF or PowerPoint
- **Docs:** Collaborative document creation with Claude, shareable via link, editable on mobile
- **Cross-device continuity:** Start work on desktop, monitor progress on mobile

Rollout is initially limited to Pro and Max plan subscribers across web, desktop, and mobile, with free and team tiers to follow later.

This follows an earlier upgrade to Cowork's memory layer, which enables Claude to retain user context across separate chat sessions.
