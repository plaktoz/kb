# OWASP Web Security Testing Guide

The Web Security Testing Guide is the premier cybersecurity testing resource for web application developers and security professionals. It provides a framework of best practices used by penetration testers globally, created through collaborative efforts of cybersecurity professionals and volunteers. Licensed under CC BY-SA 4.0.

## Current Status

- **Stable/Latest Release:** v4.2 (released 2020-12-03)
- **In Development:** v5.0
- Available as web-hosted content and PDF download

## Scenario Identifier Format

Each test scenario uses the format `WSTG-<category>-<number>` (e.g., `WSTG-INFO-02`). For cross-version referencing, the recommended format includes version: `WSTG-<version>-<category>-<number>`.
