# Cloudflare AI Gateway


**Observe and control your AI applications.**

Available on all plans.

## Overview

Cloudflare's AI Gateway provides visibility and control over AI apps, offering analytics, logging, caching, rate limiting, and request retries. Setup requires "one line of code to get started."

## Features

- **Models** – Browse AI models including OpenAI, Anthropic, Google, and more
- **Analytics** – Track requests, tokens, and application costs
- **Logging** – Gain insight on requests and errors
- **Caching** – Serve responses from Cloudflare's cache for faster, cheaper requests
- **Rate Limiting** – Control application scale by capping request volume
- **Request Retry and Fallback** – Improve resilience with model fallbacks on error
- **Providers** – Supports Workers AI, Anthropic, Google Gemini, OpenAI, Replicate, and others

## Related Products

- **Workers AI** – Run ML models on serverless GPUs across Cloudflare's network
- **Vectorize** – A vector database for semantic search, recommendations, and LLM memory
